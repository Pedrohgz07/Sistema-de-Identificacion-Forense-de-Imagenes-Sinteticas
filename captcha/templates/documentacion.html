Documentación técnica del proyecto

SIFIS

Sistema de Identificación Forense de Imágenes Sintéticas. Esta documentación describe el comportamiento implementado actualmente en el código.

01

1. Propósito y alcance

SIFIS analiza imágenes JPG, PNG y WEBP de hasta 10 MB para estimar si corresponden a contenido generado por IA o a una imagen real. La clasificación la realiza un modelo de Keras cargado desde model/modelo_ai_vs_real.keras.

El sistema genera además una visualización de Error Level Analysis (ELA). Esta visualización es un apoyo interpretativo: no se utiliza como entrada del modelo ni altera la clasificación.

Limitación: el resultado es una estimación probabilística y no constituye una prueba forense definitiva.
02

2. Flujo de análisis

1. Cliente: el usuario selecciona una imagen JPG, PNG o WEBP. La interfaz valida el tamaño máximo de 10 MB.
↓
2. Turnstile: Cloudflare Turnstile genera un token de verificación humana.
↓
3. API POST /analizar: Flask valida el token, limita las solicitudes y comprueba extensión, formato y contenido de la imagen.
↓
4. Procesamiento: se calcula el mapa ELA y, de forma independiente, la imagen se convierte a RGB, se redimensiona a 224 × 224 px y se recomprime en JPEG con calidad 85 para el modelo.
↓
5. Resultado: la predicción se compara con el umbral configurado en model/umbral_optimo.json; la API devuelve el veredicto, las puntuaciones y el mapa ELA.
Importante: ELA no produce un puntaje de anomalías ni participa en el veredicto. Solo se devuelve como una imagen PNG codificada en Base64.

04

4. Funciones principales de analyzer.py

cargar_umbral_decision() -> float

Lee DECISION_THRESHOLD desde umbral_optimo.json y valida que se encuentre entre 0 y 1.

ela_analysis(img, quality=90) -> str

Para JPEG compara la imagen RGB con una versión recomprimida a calidad 90. Para PNG y WEBP primero crea una base JPEG a calidad 75 y la recomprime. Amplifica la diferencia, crea una imagen PNG y devuelve su contenido codificado en Base64.

preprocess_image(img) -> np.ndarray

Convierte la imagen a RGB, la redimensiona a 224 × 224 px, la recomprime a JPEG con calidad 85 y devuelve un arreglo float32 con dimensión de lote.

clasificar_prediccion(prediction) -> str

Devuelve "IA" cuando la predicción es mayor o igual al umbral de decisión; en otro caso devuelve "REAL".

calcular_confianza(prediction, clasificacion) -> float

Para IA calcula prediction × 100; para REAL, (1 - prediction) × 100. El resultado se limita a 0–100 y se redondea a un decimal.

analyze_image(img) -> dict

Orquesta el análisis y devuelve un diccionario con prediccion, probabilidad_ia, confianza, umbral_ia y ela_imagen.

{
  "prediccion": "IA | REAL",
  "probabilidad_ia": 0.0,
  "confianza": 0.0,
  "umbral_ia": 0.0,
  "ela_imagen": "imagen PNG en Base64"
}

06

6. Seguridad y consideraciones operativas

  • Solo se aceptan extensiones JPG, JPEG, PNG y WEBP; el servidor también verifica el formato real con Pillow.
  • El tamaño máximo configurado es de 10 MB.
  • Las imágenes se procesan en memoria; la aplicación no implementa almacenamiento persistente de cargas.
  • El servicio depende de Cloudflare Turnstile. Para producción se deben configurar TURNSTILE_SITE_KEY y TURNSTILE_SECRET_KEY; opcionalmente TURNSTILE_EXPECTED_HOSTNAME.
  • El código actual no extrae ni muestra metadatos EXIF.
